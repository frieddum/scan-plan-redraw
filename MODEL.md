# Разметка и сборка

Координату пикселя считайте от левого верхнего угла исходного изображения. В модели ось Y направлена вверх. Пример полного задания — [demo.json](demo.json). Пример двух граней одной стены — [wall-detail.json](wall-detail.json).

| Поле | Что указывать |
| --- | --- |
| `image_size` | Ширину и высоту в пикселях. При обрезке пересчитайте координаты опор и геометрии. |
| `calibration.px`, `calibration.mm` | Две пары координат на изображении и соответствующие им две точки в модели. При локальном начале первую точку можно задать как [0, 0]. |
| `checks` | Массив независимых размеров. Для каждого задайте `label`, пару точек `px`, ожидаемую длину `mm` и допуск `tolerance_mm`. При превышении допуска сборка прерывается до записи результата. Пустой массив означает, что масштаб этого изображения независимо не проверен. |
| `layers` | Словарь имён слоёв. Укажите индекс цвета AutoCAD `aci`, толщину в сотых долях мм `weight` и цвет проверки `overlay` в формате #RRGGBB. |
| `entities` | Объекты модели. У каждого есть `type`, `layer` и точки в `px` либо `mm`. Для размеров с листа используйте координаты в мм, для наблюдаемых положений — пиксели. |
| `blocks` | По желанию. Словарь имён блоков со списками примитивов в локальных миллиметрах. Начало блока задаёт базовую точку. Вставка с типом `insert` принимает одну точку, `name` и необязательный угол `rotation` в градусах против часовой стрелки в модели. |

Для `line` задайте две точки, для `polyline` — последовательность вершин и при необходимости `closed: true`. Для `arc` укажите начало, промежуточную точку **на дуге** и конец. Для `circle` нужны центр и точка на окружности. Дверь в примере состоит из полотна и дуги, а в обеих гранях стены предусмотрен разрыв соответствующей ширины.

Из каталога скилла выполните команды для своего задания. Пути с пробелами заключайте в кавычки.

```console
python scan_to_cad.py prepare input.pdf work --page 1 --dpi 300
python scan_to_cad.py build work/scan.png work/model.json work/plan.dwg
python inspect_plan.py work/plan.dwg --layout Model --plot --dims
```

Файл `work/model.json` создаёт исполнитель по скану. Команда `build` сохраняет рядом с чертежом растровое наложение. Растр не встраивается в модель. Для DXF укажите выходной файл с расширением `.dxf`. Для DWG нужен установленный AutoCAD для Windows с Core Console. Чертёж собирается во временном каталоге и заменяет предыдущий DWG только после успешного обратного чтения.

У объектов выбранной трассы узнайте handles в свойствах CAD или при чтении DXF. Передайте их в порядке обхода. Для ответвления от внутренней вершины используйте `HANDLE:i:j`, где индексы начинаются с нуля. Следующая команда проверяет одну трассу между базовыми точками двух светильников в комплектном DWG. Для другого чертежа подставьте его идентификаторы и координаты.

```console
python inspect_plan.py demo.dwg --layout Model --route 45 --start 1000 -1300 --end 6200 -1300 --tol 0.01
```
